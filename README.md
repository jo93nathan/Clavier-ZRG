# ZRG Keyboard

Clavier iOS AZERTY (iPhone 8). Les touches restent normales ; chaque lettre tapée est insérée dans un style Unicode aléatoire
(gras, script, fraktur, cerclé, carré, pleine largeur, monospace…), jamais deux fois le même d'affilée.
Touche à gauche de l'espace : 🎲 (activé) / Aa (désactivé).

## Build de l'IPA
1. Mets le contenu de ce dossier sur un repo GitHub (crée .github/workflows/build.yml à la main avec le fichier build.yml fourni).
2. Actions › Build IPA › Run workflow, puis télécharge l'artefact ZRGKeyboard-ipa.
3. Installe l'IPA avec Sideloadly / AltStore.
4. Réglages › Général › Clavier › Claviers › Ajouter › ZRG Keyboard.
